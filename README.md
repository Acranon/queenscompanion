# Queen's Companion

An unofficial fan-made companion site for **Queen's Domain**.

**Site: https://acranon.github.io/queenscompanion/**

- **[Map](https://acranon.github.io/queenscompanion/map/)**: interactive 2D cutaway and 3D maps of every area, generated from the game's data, with items, chests, enemies, collectibles, save points, teleporters, shops and more. All markers start hidden, so nothing is spoiled until you switch it on.
- More is planned (bestiary, weapon and item lists, achievements).

## Live position (optional)

See where you are on the map while you play, e.g. on a second monitor, and which items and chests you have already collected.

1. Install the experimental build of [UE4SS](https://github.com/UE4SS-RE/RE-UE4SS/releases) for Queen's Domain.
2. Download [QD_MapLink.zip](https://acranon.github.io/queenscompanion/map/download/QD_MapLink.zip) and copy its `QD_MapLink` folder into `...\Binaries\Win64\ue4ss\Mods\`. The README inside the zip has the details.
3. Start the game, open a map, click **Live position...** in the left panel and tick **show where I am**. If your browser asks for access to local network devices, allow it.

The mod only reads your position and save files. It changes nothing in the game. The page talks only to a small helper on your own PC (127.0.0.1).
